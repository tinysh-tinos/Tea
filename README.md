  # Tea
  <p>Software for a smart mug coaster</p>

  # Tutorial
  <ul>
    <li>1. Install Node.js</li>
    <li>2. Install PlatformIo in VSCode</li>
    <li>3. Open folder 'chayok' in PlatformIo</li>
    <li>4. Start 'main.cpp'</li>
    <li>5. Close folder</li>
    <li>6. Open root folder</li>
    <li>7. Start 'main.py'</li>
    <li>8. Open new terminal</li>
    <li>9. Enter into terminal 'node index.js'</li>
    <li>10. Open IP from terminal in the browser'</li>
  </ul>
